# Higher Order Functions

JavaScript exercises using higher order functions (forEach and map). Each exercise has its own button on the page, and the results show in the console (F12).

## Live URL
https://abd-alrhmanfayyad.github.io/Higher-Order-Function/

## Exercises
- **Ex1:** Raise 2 to the power of each number, solved with for, forEach and map
- **Ex2:** Use map to label each value as even, odd or N/A
- **Ex3:** Use forEach to print and return all the names in an array
- **Ex4:** FizzBuzz using map
